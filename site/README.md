# Grounded AI Agents with Neo4j and AWS Workshop Site

This directory holds both the authored workshop content and the Antora
microsite that publishes it.

| Path | What it is |
|---|---|
| `content/` | The workshop pages, in Markdown. The single source of truth. |
| `images/` | Diagrams referenced by those pages. |
| `scripts/`, `antora.yml`, `nav.adoc` | The build that converts the above into the published site. |
| `modules/`, `build/` | Generated by the build. Never edit these; they are gitignored. |

To change a lesson, edit the page under `content/`. Add or replace a diagram in
`images/` and reference it from the page with the existing `:image[...]`
directive.

## Run locally

```bash
cd site
npm ci
npm run build
npm run serve
```

Open http://localhost:8080. This needs Node.js and
[Pandoc](https://pandoc.org/). The production deployment is handled by
`.github/workflows/deploy-site.yml` whenever `site/` changes on `main`.
